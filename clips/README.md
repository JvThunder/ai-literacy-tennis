Example sessions shown on the site. `training_<n>.mp4` are forehands cut from the team's practice videos by
`make_examples.py` (one clear forehand per video, checked by eye; a `_left`/`_right` suffix sets the hitting hand); `thetis/` holds the earlier THETIS examples.
Add a clip here and run `TENNIS_MODE=api .venv/bin/python precompute.py` to rebuild the example sessions.
